İçerik Yönetimi

Güncel Dosyalar — 3 İçerik Bloğu

Aşağıdaki 3 alanı doldurup “Kaydet”e bastığınızda değişiklikler bu tarayıcıda saklanır ve ana sayfada (aynı cihazda) hemen görünür. Değişikliklerin tüm ziyaretçilerde görünmesi için “JSON Dışa Aktar” ile indirdiğiniz content.json dosyasını GitHub deponuza yükleyip mevcut dosyanın üzerine yazmanız gerekir.

Nasıl çalışır?
1) Metinleri ve görselleri doldurun → 2) “Kaydet” ile tarayıcıya kaydedin ve önizleyin → 3) “JSON Dışa Aktar”a basıp inen content.json dosyasını GitHub deponuzdaki mevcut content.json ile değiştirin → 4) GitHub Pages birkaç dakika içinde günceller.
